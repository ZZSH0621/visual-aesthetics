摄影属性

摄影机在静态拍摄状态下形成画面的基础观看条件——决定画面从哪里看、以什么距离看、通过什么镜头看，以及画面的基础成像形态。

不是摄影机运动，也不处理画面内部元素的运动，而是构成影像观看方式的底层条件。范畴包括：景别、机位、拍摄角度、镜头、焦点、景深、曝光、畸变等。

Module 01 · Shot Size

景别

摄影机与被摄主体之间形成的画面距离关系，体现为主体在画面中所占比例的大小。它决定观众与人物、事件、空间之间的观看距离，影响画面的信息量、情绪强度和叙事重点。

景别不是绝对距离，而是比例关系——长焦可以在 50 米外拍出特写，广角可以在 1 米内拍出远景。景别衡量的永远是"主体在画框中的占比"。

景别光谱 · 从环境到细节

功能 交代背景、抒发情感、史诗感

人物全身可见，保留较多环境信息。
功能 突出人物与环境的关系

功能 展示身体动作与姿态

功能 表情 + 肩手姿态兼得

Extreme Close-up

景别判定方法
场景判定规则
单人画面按人物在画面中的截取部位直接划分
多人 · 相对景深法以最靠近镜头的人物为衡量标准
多人 · 独立景框法以独立景框内的人物为衡量标准（如窗外的孩子 → 远景）
长焦多景深谁清晰认准谁——以焦平面上的人物为准
镜中人物不作参考——镜中空间与拍摄方向无准确对应关系
无人画面以被摄目标所在焦平面放置一个"虚拟人物"再判定

A 类划分自由粗疏，适合日常沟通；B 类划分精准细致，适合分镜脚本与教学。"相对景深法"看最近的人，"独立景框法"看框里的人——同一画面用不同方法，结论可以完全不同。

景别的心理学
  • 亲密度的物理化 — 霍尔的空间关系学：景别本质是在银幕上复刻"亲密/个人/社交/公共"四层人际距离
  • 权力的尺度 — 人物占比越小越被环境支配，占比越大越支配画面
  • 信息的配额 — 景别越紧环境信息越少、情绪越多；景别越松情绪越冷、越客观
AI 视频生成 Prompt 示例
大远景

电影感视频：大远景，荒漠黄昏，一个孤独旅人走在广阔沙地中央，人物只占画面很小比例，天空巨大，风沙轻微流动，画面强调环境尺度与人物渺小感，写实电影质感。

中近景

夜晚车内，一名年轻女性坐在驾驶座上，画面从胸口到头部入画，她双手紧握方向盘，眼神紧张地看向前方，车窗外霓虹灯和雨滴虚化成光斑，低调光，真实悬疑电影质感。

特写

一只微微颤抖的手按下老旧电梯按钮，按钮边缘有磨损和指纹，金属表面反射冷光，背景完全虚化，紧张悬疑氛围。

极特写

人物的一只眼睛占满画面，瞳孔中倒映出远处燃烧的火光，睫毛和皮肤纹理清晰，眼神恐惧，暗部细节丰富，电影级写实质感。

常见错误
  • 景别跳切混乱 — 同一场戏景别忽远忽近没有逻辑
  • 特写滥用 — 什么都特写，稀释了特写的情绪力量
  • 大远景没耐心 — 建立镜头切太快，观众还没看清环境
  • Prompt 比例含糊 — 只说"拍一个人"，不说明截取部位
  • 忽略焦段关系 — 广角近拍特写会严重变形人脸

"景别 = 观众与故事的心理距离"

导演握住观众视线的第一只手——决定"让观众站多远看"。

Module 02 · Camera Position

机位

通俗讲就是"摄影机在哪里"——摄影机在空间中的放置位置，包括高度、距离、方位和拍摄平台。它影响画面的空间感、权力关系、临场感和视觉立场。

机位 ≠ 拍摄角度：机位回答"摄影机在哪里"，角度回答"摄影机朝哪个方向拍"。

基础机位 · 高度即权力
Eye-level
平视机位
高度接近人物眼睛，形成自然、客观、日常的观看关系。
场景 对话、纪实采访
High Position
高机位
位于主体上方向下观看。
情绪 弱小、被观察、被压制
Low Position
低机位
低于主体向上观看。
情绪 力量、压迫、英雄感
Ground-level
地面机位
极低接近地面。
情绪 地面质感、脚步、危险逼近
Shoulder-level
肩部机位
高度接近人物肩部。
场景 跟拍、手持、现实感
Top-down
顶视机位
主体正上方垂直向下。
情绪 图案、布局、命运感
特殊机位 · 立场即叙事
无人机机位
空中视角，高度、广域空间、漂浮观察感。

高处广角静止，冷漠观察与证据感。

固定于运动物体，非人称奇异视角。

门缝、窗帘、柜后偷看，悬疑与不安全感。

通过镜子/玻璃/反射面观看，身份与分裂。

机位的四个维度
高度 Height权力关系：高=压制，低=敬畏

奥逊·威尔斯拍《公民凯恩》时砸开摄影棚地板，只为把摄影机放得更低——机位高度是最直观的"权力语法"。

低机位

黑衣反派站在雨夜街头，摄影机贴近地面向上拍摄，他的身形显得高大压迫，背后霓虹灯闪烁，雨水反光，黑色电影质感。

地面机位

摄影机贴近泥泞地面，一队士兵的靴子从镜头前快速跑过，泥水飞溅到画面边缘，背景烟尘弥漫，战争电影质感。

监控机位

便利店深夜空无一人，画面来自天花板角落的固定监控摄像头，高处广角视野，画质略粗糙，时间码感，货架间突然有影子闪过。

物件机位

视角仿佛固定在一个红色行李箱上，行李箱被人拖着穿过机场大厅，地面快速滑过，周围人群从两侧掠过，画面有轻微震动。

隐藏窥视

视角从半掩的门缝中看向客厅，两个人正在低声争吵，画面边缘被门框遮挡，室内灯光昏黄，气氛紧张，悬疑片质感。

水下机位

摄影机位于泳池水下，蓝绿色水体中气泡上升，一个人影从水面坠入，阳光在水面形成波纹折射，动作缓慢，声音沉闷。

常见错误
  • 机位与情绪错位 — 拍受害者却用低机位，权力关系反了
  • 忽略轴线 — 对话戏机位随意跨轴，观众失去方向感
  • 特殊机位滥用 — 监控/窥视/无人机是调味料，不是主菜
  • 高度描述含糊 — Prompt 只写"俯拍"，模型分不清机位还是角度
  • 忘记物理逻辑 — 水下机位没有折射气泡，物件机位稳如三脚架

"机位 = 观众的座位"

你把观众放在哪里，观众就站在谁的立场上看这个故事。

Module 03 · Camera Angle

拍摄角度

"摄影机怎么拍"——摄影机相对于被摄主体的观看方向和倾斜关系。它决定主体以何种姿态、方位和视觉关系被呈现，用于塑造人物状态、空间压迫感、心理不稳定感或叙事立场。

机位管位置（高度/距离/平台），角度管方向与倾斜（正/侧/背/俯/仰/斜）。

基础角度
Front Angle
正面
正对主体，信息清楚、关系直接。
场景 肖像、对峙、陈述
Side Angle
侧面
从主体侧面拍摄，强调轮廓与动作线。
场景 行走、距离感
Back Angle
背面
从主体背后拍摄，去身份化。
情绪 目的地、孤独、悬念
Three-quarter
三分侧
斜前/斜后方，兼具面部信息与空间方向。
场景 好莱坞对话默认角度
High Angle
俯拍
从上方向下看主体。
情绪 弱小、受困、被审视
Low Angle
仰拍
从下方向上看主体。
情绪 强大、压迫、英雄感
Bird's-eye
鸟瞰
高空向下（非完全垂直）。
场景 空间格局、宏观关系
Selfie
自拍
前置广角近距离，突出五官、强烈眼神交流。
特征 边缘脸型拉宽
特殊角度 · 深度解析
Dutch Angle
荷兰角
摄影机水平线倾斜，地平线/垂直线不再与画框平行。出处与德国表现主义电影传统有关，《第三人》是经典用例。机位不变，机身向左或右倾斜即可。
用途 心理不安、空间扭曲、危险逼近、精神失控
First-person POV
第一人称视角
摄影机模拟角色眼睛看到的画面，强化沉浸和代入。又称主观视角。
场景 恐怖、动作、沉浸叙事
Rear Three-quarter
斜后方追随
位于主体后方偏左/右约 30–60°，跟随运动，同时保留背影、侧轮廓与前方空间方向。观众既能"跟着角色走"，又能看到角色即将进入的空间。
场景 动作片、游戏视角、潜行
God's-eye View
神视角 / 上帝视角
极高处接近垂直俯视，人物与群体呈现图案化、棋盘化、命运化关系。鸟瞰偏空间观察，顶视偏垂直角度，神视角强调超越角色的全知俯察。经典用例：《杀死比尔》室内顶视——构图如一盘棋局。
场景 韦斯·安德森式构图、犯罪现场、群体仪式
Worm's-eye View
蚁视
从极低位置向上看，模拟蚂蚁视角，视角接近地面。
情绪 庞大、压迫、奇观感
CCTV Angle
监控视角
模拟监控摄像头的固定广角倾斜视角。
情绪 冷漠、非叙事化、证据感
Reverse Angle
反打角度
一个镜头之后，从约 180° 相反方向拍摄关系中的另一方。不是固定角度，而是一种镜头关系角度：先建立一方视线/动作方向，再切到另一方对应角度，保持空间轴线清楚。
用途 对话节奏、反应信息、空间连续性
Over-the-shoulder
过肩角度 OTS
从一名角色肩膀后方看向另一名角色。肩部是前景关系参照物而非主体——通常不要超过画面 1/3，超过就从"关系提示"变成"遮挡式构图"或"压迫式过肩"。
场景 对话、对峙、关系建立
过肩镜头 · 肩部占比四分法
类型肩部占比效果
轻过肩5%–15%前景肩部只是轻微提示人物关系，画面更干净 [示例]
标准过肩15%–30%最常见，保留前景人物存在感，又不遮挡对方表情
重过肩30%–45%前景人物压迫感强，用于审讯、威胁、亲密压迫 [示例]
极重过肩45% 以上前景肩背几乎吞掉画面，带窥视、阻隔、压迫、主观感

AI 视频生成 Prompt 示例
荷兰角

夜晚空荡地铁站，一名男子突然停下脚步，画面整体向右倾斜，灯光闪烁，远处隧道黑暗，营造心理失衡和危险逼近感。

背面角度

一个穿长外套的人背对镜头，独自走向昏暗隧道深处，隧道灯光一盏盏延伸，人物身份不可见，悬疑氛围强烈。

过肩角度

摄影机位于警探肩膀后方，前景是警探模糊的肩部轮廓，焦点落在桌对面的嫌疑人脸上，审讯室灯光冰冷，气氛紧张。

反打角度

餐桌对话中，画面从女性的视线方向反打到男性正面，男性沉默地看向她，桌面蜡烛在前景虚化，气氛尴尬压抑。

斜后方追随

摄影机从主角右后方跟随，他穿过拥挤夜市，人群从两侧擦过，主角背影清晰，前方霓虹灯延伸，带有潜行和目标感。

神视角

极高空俯视一座白色广场，数百人缓慢移动形成圆形队列，画面几何秩序强烈，人物像微小符号，氛围冷静而庄严。

常见错误
  • 荷兰角滥用 — 必须有心理依据：角色失控、世界失衡时才用
  • 反打乱轴 — 跨越 180° 轴线，观众分不清谁在看谁
  • 过肩遮挡过度 — 肩部超 1/3 却没意识到压迫感，与情绪错位
  • 背面角度没耐心 — 悬念需要时长发酵，切太快就浪费了
  • 神视角高度不够 — 只有普通俯拍高度，图案感出不来

"拍摄角度 = 叙事的态度"

平视是尊重，俯视是审判，倾斜是失控。

Module 04 · Lens

镜头

运用不同焦段、不同类型的镜头拍摄带来的视觉效果——透视变形、空间压缩或拉伸、视野范围和主体突出方式。它决定画面的光学质感、空间关系和视觉风格基础。

变焦改变焦距，推拉改变摄影机位置——两者完全不同。空间压缩不是"走近了"，是长焦的光学特性。

焦段光谱 · 两大物理效应
14–20mm
超广角
视野极宽，透视明显拉伸，近大远小被夸张，边缘易变形。
场景 宏大空间、狭窄室内、极限运动
21–35mm
广角
视野宽于人眼，容纳更多环境，强化前后景距离。18/24/25mm 是电影典型广角。
场景 街景、动作、环境叙事
35/50mm
标准镜头
接近人眼自然观看比例，透视自然，不夸张也不压缩。
场景 日常叙事、纪实
70–100mm
中长焦
开始明显压缩空间，背景拉近，主体突出，易虚化。75/85/100mm 常见于电影定焦组。
场景 肖像、情绪特写
100mm+
长焦
空间压缩更强，远处背景贴近主体。
情绪 窥视、隔离、监视感
200mm+
超长焦
压缩极强，画面晃动和空气扰动更明显。
场景 野生动物、体育、战争观察
特殊功能镜头
变焦镜头
焦距连续变化（24–70、70–200），机位不动画面缩放。经典：希区柯克变焦（动图示例）。
微距镜头
极近拍摄、高放大倍率，放大纹理、昆虫、液体、皮肤细节。
鱼眼镜头
极端超广角（6–16mm），球面畸变，画面边缘弯曲，怪诞失控。
变形宽银幕
横向压缩再展开：宽银幕比例、水平眩光、椭圆散景。同源焦距下水平视野更广、物距更近、景深更浅。
移轴镜头
Shift 校正建筑透视；Tilt 改变焦平面，制造微缩模型感。
分裂焦点镜
前后景同时清晰，中间略异常。Brian De Palma 标签化使用，《Carrie》经典用例。
探针镜头
细长管状深入狭窄空间，"进入物体内部"的奇观视角，食品/产品广告常客。
软焦镜头
高光扩散、边缘变柔，复古肖像、梦境、浪漫、旧电影质感。
模拟类镜头 · 媒介质感

镜头示例
变形宽银幕小史

早期可追溯到 Henri Chrétien 的 anamorphoscope，1950 年代 CinemaScope 让它成为重要的电影宽银幕技术。水平蓝色眩光和椭圆焦外，是"电影感"最廉价也最贵的签名。

超广角

滑板运动员从城市广场台阶上跃起，身体靠近镜头时产生夸张透视变形，背景建筑被拉伸，动作充满冲击力，运动广告质感。

长焦

城市长街尽头，一名男子站在人行道上，远处车辆和建筑被压缩到他身后，背景密集，人物显得被城市挤压，冷色写实风格。

变焦

远处广场人群中，一个穿红衣的人突然回头，镜头从中远景快速变焦到他的上半身，摄影机位置不变，画面带有纪录片抓拍感和紧张感。

鱼眼

狭小电梯内，一个人突然靠近镜头，鱼眼畸变让他的脸和电梯墙壁夸张弯曲，灯光闪烁，画面带有怪诞恐怖感。

变形宽银幕

夜晚雨中街道，一辆汽车缓慢驶过，车灯形成明显水平蓝色眩光，背景霓虹椭圆散景，宽银幕电影质感，画面高级冷峻。

移轴

从高处俯视繁忙城市街道，车辆和行人像微缩模型一样移动，画面上下区域柔和虚化，中间清晰，色彩明亮，玩具城市质感。

微距

清晨叶片上的一颗水珠缓慢滑落，水珠内倒映出天空和树影，叶脉纹理清晰可见，背景完全虚化，细腻自然纪录片质感。

探针

镜头穿过透明冰块、柠檬片和气泡水之间，极近距离展示水珠、气泡和果肉纹理，空间狭窄但清晰，清爽商业广告质感。

常见错误
  • 变焦与推拉混淆 — 变焦透视不动，推拉透视变化，Prompt 写错运动逻辑就错
  • 广角拍人脸特写 — 鼻子大耳朵小脸变形，人像特写请用 85mm+
  • 压缩的误归因 — "背景好近"不是场景近，是长焦压缩
  • 鱼眼没有畸变 — 必须明确写"画面边缘弯曲、球面畸变"
  • 移轴只有虚化 — 微缩感的关键是高机位俯拍 + 局部清晰带

"镜头 = 光学世界观的开关"

选镜头就是选择让观众相信哪一种物理法则。

Module 05 · Image Formation

成像属性

画面最终形成的视觉成像特征——焦点、景深、曝光、散景、畸变、眩光和色差等。它决定画面的清晰关系、视觉层次、质感表现和影像真实感。

景别、机位、角度、镜头决定"怎么拍"，成像属性决定"拍出来长什么样"。

三个必须厘清的"距离"
Camera ↔ Subject
机位
主语是"摄影机"——摄影机从多远、多高、何方位去拍摄被摄物。
Focus Plane
焦点
"清晰层"离"镜头"的距离——是一个"切片"，画面中最清楚的距离层面。
Depth Range
景深
焦点前后还能保持清晰的范围——是有"厚度"的范围。
焦点 Focus · 注意力落在哪里
固定焦点
焦点始终停留在同一主体/距离层，稳定强调主体。
前景焦点
焦点在前景物体，背景主体模糊——强调物件、遮挡、悬念。
中景焦点
焦点落在中间距离层，人物主体或主要事件（最常用）。
背景焦点
焦点在远处背景，前景虚化——窥视、揭示远处信息。
焦点转移
Rack Focus / 拉焦：焦点从一个距离层转移到另一个，引导注意力。
失焦
主体故意不清晰——眩晕、梦境、醉酒、记忆、心理混乱。
呼吸式对焦
对焦变化时画面视角轻微变化，像镜头在"呼吸"。
分离焦点
两个不同距离主体同时清晰，由分裂焦点镜实现。
景深 Depth of Field · 清晰范围的厚度
Shallow DOF
浅景深
只有焦点附近清晰，前后景明显虚化。实现：大光圈 + 中长焦/长焦（50/85/100/135mm）+ 靠近主体 + 主体离背景远。又称背景虚化、大光圈、浅焦。
Prompt 关键词 extremely shallow depth of field, f/1.2, 85mm, cinematic bokeh, subject isolation
Deep Focus
深景深
前景、中景、背景大范围保持清晰。实现：小光圈 + 广角/标准（18/24/28/35/50mm）+ 焦点落中间距离。又称深焦、小光圈、大景深。
场景 空间关系、群像、建筑、深焦调度
Moderate / Selective
中等景深 · 选择性景深
中等：主体清晰、背景略虚但环境可辨（35–70mm 中光圈）。选择性：极有限清晰范围只让某个局部清晰，焦点精确落在眼睛/手指/物件。
场景 既突出人物，又保留环境叙事
Miniature / Layered
微缩景深 · 分层景深
微缩：只有一条局部清晰带，真实场景像玩具模型（移轴或后期 + 高机位俯拍）。分层：前中后景不同清晰程度，制造纵深和观看引导。

AI 视频生成 Prompt 精选
浅景深（完整版）

黄昏时分的城市街道，一位年轻女子站在路边安静地看向远方。镜头采用 85mm 长焦镜头与超大光圈拍摄，极浅景深效果。摄影机缓慢向前推进，焦点始终锁定在女子的眼睛和面部细节上。前景行人与路边花朵形成柔和虚化，背景霓虹灯、车流灯光完全融化成梦幻般的彩色散景光斑（Bokeh）。暖金色夕阳勾勒出人物轮廓光。电影级摄影，真实光学景深，细腻焦点过渡。

焦点转移

前景桌上的咖啡杯一开始清晰，背景人物模糊；随后焦点缓慢从咖啡杯转移到背景中沉默的男人脸上，室内安静，浅景深，情绪压抑。

剪影曝光

夕阳下的山脊上，一个人站在风中，背景天空明亮金红，人物完全成为黑色轮廓，衣摆被风吹动，画面孤独而史诗。

长曝光

夜晚高架桥上车辆快速经过，车灯形成红白色光轨，建筑稳定清晰，天空深蓝，画面呈现时间流动和都市速度感。

常见错误
  • 景深想要却得不到 — 只写"背景虚化"不够，要给焦段 + 光圈 + 距离的组合逻辑
  • 曝光三角只提一个 — 说 ISO 3200 却忘了设定暗光场景，逻辑不自洽
  • 颗粒与噪点混用 — 胶片颗粒是有机质感，数字噪点是电子粗糙
  • 畸变没有物理来源 — 水下折射不写水体，热浪畸变不写高温
  • 追求"完美画质" — 低清、噪点、污渍、闪烁恰恰是真实感的来源

"成像属性 = 画面的皮肤与质感"

焦点决定看哪里，景深决定看清多少，曝光决定亮暗情绪，畸变与颗粒决定这画面可不可信。
